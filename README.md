# Portafolio · Edgar Adrián Guzmán Vargas

Sitio personal en español e inglés. Muestra mi perfil, experiencia, proyectos, habilidades y formación.

Personal site in Spanish and English: profile, experience, projects, skills and education.

## Tecnologías

React · TypeScript · Vite. Sin dependencias de interfaz extra: los estilos son CSS propio con tema claro y oscuro según el sistema.

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Compilar

```bash
pnpm build
pnpm preview
```

## Contenido

Todo el texto está en `src/data/perfil.ts`, separado por idioma (`es` y `en`). Para actualizar el sitio basta con editar ese archivo.

## Despliegue

Vercel detecta Vite automáticamente: comando `pnpm build`, carpeta de salida `dist`.
